# 🏠 智居 · 智能家居场景联动与设备健康看板

基于 **Vue 3 + Vite + Pinia（前端）+ Express + SQLite（后端）** 的智能家居演示看板。纯 mock 设备数据，无真实硬件接入。

## 技术栈

- 前端：Vue 3 + Vite + Pinia
- 后端：Node.js 内置 `node:sqlite` + Express，REST API
- 数据库：`server/home.db`（SQLite，首次启动自动建表 + 预置演示数据）

## 运行

```bash
npm install
npm run dev
```

前端 http://localhost:5190（Vite 已代理 `/api` 到 http://localhost:4120）。
需 Node ≥ 22.13。

## 功能

- **健康看板**：设备在线/异常统计、房间分布、设备类型、告警中心（低电量/信号弱/离线/能耗尖峰）、全屋 24h 能耗趋势
- **设备管理**：按房间/类型/状态筛选，添加/删除设备，开关切换，功率编辑、电量/信号条
- **场景联动**：可视化动作编排（设备→动作），创建/启用停用/触发场景，触发后写入日志并联动开关真实设备状态
- **能耗统计**：按设备开关/功率变化分段累计用电（功率×时长），近24小时总量、按房间分布、设备用电排行、实时功率、节能提示；已删除设备历史保留并标记
- **日志时间线**：所有操作的实时记录

## 分段用电模型

- `energy_segments`：每台开启运行中设备的段首（设备标识 + 名称/房间/功率快照 + 起始时间）。开关切换、功率编辑、改名、换房时旧段立即结落，再按当前状态开新段
- `energy_records`：结落的分段明细，按 `device_id` 稳定归属（删除设备不级联），含完整 ISO 起止时间、产生时的名称/房间快照与 kWh；服务端每 30s 模拟运行节拍结段续开，明细保留 7 天
- 旧版 `energy(device_name,room,kwh,hour)` 数据首次启动自动迁移：名称唯一命中的绑定设备标识，重名/设备已删除的不猜绑，保留名称房间快照（排行中标记「旧记录」）
- 看板 24h 趋势、能耗排行与尖峰告警均读自分段记录；前端 20s 自动刷新

## 数据库表

`rooms` `device_types` `devices` `scenes` `scene_actions` `device_logs` `energy_records` `energy_segments`
